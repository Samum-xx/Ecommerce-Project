# Анализ транзакций — курсовая работа

Консольное приложение для анализа банковских транзакций из Excel-файла.
Формирует JSON-ответы для веб-страниц «Главная» и «События», предоставляет
сервисы (кешбэк, «Инвесткопилка», поиск, переводы) и отчёты (траты по
категории, по дням недели, в рабочий/выходной день).

## Структура проекта

.
├── src/
│   ├── __init__.py
│   ├── utils.py        # чтение Excel-файла, приветствие, настройки
│   ├── main.py         # точка входа: CLI на argparse
│   ├── views.py        # страницы «Главная» и «События»
│   ├── services.py     # сервисы: кешбэк, инвесткопилка, поиски, переводы
│   ├── reports.py      # отчёты: траты по категории/дням/типу дня
│   └── decorators.py   # декоратор сохранения отчётов в файл
├── tests/              # pytest-тесты всех модулей
├── data/
│   └── operations.xlsx # файл с транзакциями
├── user_settings.json  # валюты и акции пользователя
├── .env_template       # шаблон переменных окружения
├── .flake8             # конфигурация линтера
├── pyproject.toml
└── requirements.txt


Бизнес-логика отделена от получения данных: функции принимают список
транзакций или датафрейм, а чтение файла выполняет отдельная функция
"get_transactions". Это позволяет тестировать логику на подготовленных
данных без обращения к файлу.

## Внешние API

Курсы валют получаются через бесплатный API **open.er-api.com** (без ключа),
цены акций S&P 500 — через публичный **Yahoo Finance** (без ключа).
При недоступности API приложение не падает: соответствующие блоки ответа
возвращаются пустыми списками, ошибка фиксируется в логе.

## Установка и запуск

python -m venv .venv
.venv\Scripts\activate        # Windows

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Положить файл транзакций в data/operations.xlsx
# 4. При необходимости отредактировать user_settings.json:
#    списки валют и акций для отображения


## Команды

Команда - Назначение                                            
 "main" - Главная страница: приветствие, карты, топ-5 транзакций, курсы валют, акции
 "events" | События за период W / M / Y / ALL
 "cashback" | Выгодные категории повышенного кешбэка
 "invest" | «Инвесткопилка»: сумма округления трат
 "transfers" | Переводы физлицам (опционально за месяц)
 "recipients" | Топ-5 получателей переводов за месяц
 "search" | Простой поиск по описанию и категории
 "phones" | Поиск транзакций с мобильными номерами
 "category" | Отчёт: траты по категории за 3 месяца
 "weekday" | Отчёт: средние траты по дням недели
 "workday" | Отчёт: средние траты в рабочий/выходной день

### События за месяц

bash
python -m src.main events "2024-07-30 18:00:00" --period M


json
{
  "expenses": {"total_amount": 378124, "main": [...], "transfers_and_cash": [...]},
  "income": {"total_amount": 171629, "main": [...]},
  "currency_rates": [...],
  "stock_prices": [...]
}


Поддерживаются периоды "W" (неделя), "M" (месяц), "Y" (год) и "ALL"
(все данные до даты). В «main» выводятся топ-7 категорий по убыванию,
остальные суммируются в «Остальное»; «transfers_and_cash» содержит
категории «Наличные» и «Переводы». Суммы округлены до целых.

### Выгодные категории кешбэка

bash
python -m src.main cashback --year 2024 --month 7


json
{"Переводы": 3781.24}


Считается кешбэк (1 рубль на каждые 100 рублей расходов) по каждой
категории за указанный месяц; доходы не учитываются.

### Инвесткопилка

bash
python -m src.main invest --month 2024-07 --limit 50



375.68


Траты округляются вверх до кратности порогу (10/50/100), разница
попадает в «Инвесткопилку». Доходы не откладываются.

### Поиск

bash
python -m src.main search --query "Перевод"


Поиск ведётся по подстроке в описании и категории, регистр не важен.

### Поиск по телефонным номерам

bash
python -m src.main phones


Поддерживаются форматы "+7 921 11-22-33", "+7 (995) 555-55-55",
"89000000000". В тестовой выгрузке телефонных номеров нет, поэтому
результат — корректный пустой список "[]".

### Отчёты

bash

month     spent  operations
2024-06  78500.51          22
2024-07 378124.32          96

weekday  average_spent
Понедельник        4174.75
Вторник            5264.34
...

python -m src.main workday "2024-07-30 18:00:00"

day_type  average_spent
Выходной        3383.77
Рабочий         4020.88


Каждый отчёт показывает данные за последние три месяца от переданной
даты; если дата не указана — от текущей. Результат каждого отчёта
сохраняется в файл благодаря декоратору: вариант без параметра —
имя файла по умолчанию, вариант с параметром — указанное имя файла.
