# E-commerce project (bank-coursework)

## Функционал
- Реализованы классы `Product` и `Category`.
- В классе `Category` добавлены атрибуты класса `category_count` и `product_count`, которые автоматически обновляются при инициализации объектов.
- Написаны юнит-тесты на инициализацию объектов и проверку счётчиков. Покрытие тестами >75% (или укажи реальное, если замерял).
